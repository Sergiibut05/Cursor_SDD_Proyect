# Implementar una tarea

Encarga el trabajo al subagente `implementador`. No implementes la tarea en este chat.

1. El id es el que indique quien escribe (por ejemplo `T3`). Si no hay id, pregunta cuál es y no delegues todavía.
2. Delega en `implementador` ese id. Debe seguir la skill `seguir-spec`.
3. Cuando devuelva el resultado, delega la comprobación de esa misma tarea en el subagente `revisor-spec`.
4. No encargues otras tareas ni el cambio de requisitos C1.
